# Python Development Rules

## 1. 仮想環境とパッケージ管理
- Python の実行・パッケージインストールは、必ずプロジェクト直下の `.venv` 仮想環境を使用すること。
- 新しい依存関係を追加した場合は、`requirements.txt` を更新すること。

## 2. コーディング規約
- PEP 8 に準拠したコードを書くこと。
- 関数の引数および戻り値には、原則として型ヒント（Type Hints）を付与すること。
- 日本語のコメントや docstring を適切に記述すること。
- エントリーポイントは `main.py` とし、再利用可能なロジックは別モジュールに分割すること。

## 3. テストと動作確認
- コードを作成・変更した後は、可能な限り実行確認やユニットテストを行うこと。
